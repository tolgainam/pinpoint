# Pinpoint

Pin comments to elements on a localhost page and dispatch them, with screenshots, into a
running Claude Code or Cowork session on your computer.

This folder is the Claude Code plugin. It runs one local Node process and has no dependencies.
Install it with `/plugin install pinpoint --marketplace tolgainam/pinpoint`, then run
`/pinpoint:setup` to get the browser extension from your browser's store and to check
that everything is connected.

Documentation: https://github.com/tolgainam/pinpoint#readme
